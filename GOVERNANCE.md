# Governance

## Overview

WindNinja is an open-source project developed and maintained by the U.S. Forest Service Missoula Fire Sciences Laboratory and its collaborators. The project welcomes contributions from the broader community.

## Maintainers

Project maintainers are responsible for:

* Reviewing and merging contributions.
* Maintaining the codebase and project infrastructure.
* Making technical decisions about the project.
* Managing releases and significant changes to the software.
* Ensuring that contributions comply with the project's license and contribution requirements.

The current list of maintainers is maintained in the project documentation or repository.

## Contributions

Contributions are welcome through pull requests and other development activities described in `CONTRIBUTING.md`.

Contributors should follow the project's coding standards and contribution guidelines. All contributions are subject to review before being incorporated into the main codebase.

## Decision Making

The maintainers generally make decisions by consensus. Technical decisions should consider:

* Correctness and scientific validity.
* Software quality and maintainability.
* Compatibility with existing WindNinja functionality.
* Usability for the WindNinja community.
* Long-term sustainability of the project.

For significant or potentially disruptive changes, maintainers may seek input from project contributors and users before making a final decision.

## Project Leadership

WindNinja is a Missoula Fire Sciences Laboratory project. The Missoula Fire Sciences Laboratory is responsible for the overall direction and stewardship of the project.

The WindNinja project leadership is responsible for:

* Establishing the project's overall goals and priorities.
* Providing organizational oversight of the project.
* Designating project maintainers.
* Approving significant changes to project direction, licensing, or governance.
* Making final decisions when consensus cannot be reached among maintainers.

Day-to-day technical decisions are delegated to the project maintainers.

## Changes to Governance

This document may be updated by the project maintainers as the project evolves.
